# oh-my-forge — Laravel + Vue + Inertia Preset

Stack-specific agents and rules for Laravel + Inertia.js + Vue 3 + Tailwind CSS projects.

## Install

```bash
./scripts/install.sh /path/to/your/laravel-project --preset laravel-vue
```

## What's Included

### Additional Agents

- `laravel-expert` — Eloquent, Blade, middleware, service providers
- `inertia-specialist` — Shared data, forms, SSR, partial reloads
- `vue-composer` — Composition API, Pinia, Vue Router patterns

### Custom Rules

- PSR-12 for PHP, ESLint + Prettier for JS/Vue
- Artisan commands for scaffolding
- Laravel naming conventions (snake_case DB, camelCase JS)
- Inertia-specific patterns (useForm, shared props, lazy loading)
